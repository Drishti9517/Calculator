# Basic Calculator Console Program

A simple Java console-based calculator that performs basic arithmetic operations using user input.

## 📌 Description

This project is a basic calculator developed in Java. It allows the user to perform:

- Addition
- Subtraction
- Multiplication
- Division

The program also includes input validation and exception handling to handle invalid number inputs and prevent division by zero.

The user can perform multiple calculations until they choose to exit.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🛡️ Handles invalid number inputs
- 🚫 Handles division by zero
- 🔄 Allows multiple calculations
- 📋 Uses separate methods for arithmetic operations
- 💻 Simple console-based interface

## 🛠️ Technologies Used

- **Java**
