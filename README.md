Basic Calculator Console Program

A simple Java console-based calculator that performs basic arithmetic operations using user input.

📌 Description

This project is a basic calculator developed in Java. It allows the user to perform addition, subtraction, multiplication, and division.

The program also includes input validation and exception handling to handle invalid number inputs and prevent division by zero. The user can perform multiple calculations until they choose to exit.

✨ Features
Addition
Subtraction
Multiplication
Division
Handles invalid number inputs
Handles division by zero
Allows multiple calculations
Simple and beginner-friendly console interface
Uses separate methods for arithmetic operations
